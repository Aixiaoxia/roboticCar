# 跟随参数统一配置

## 只编辑这一个入口

```text
/home/aixiaoxiao/agx_ws/follow_config.yaml
```

该入口是源码配置的软链接，不是另一份副本。
总启动、单独跟随启动和包内默认配置实际指向同一份内容，不需要在源码和 install 目录分别改参数。
不要删除软链接后另外创建一份同名文件；直接用编辑器打开并保存即可。

例如用 VS Code 打开：

```bash
code ~/agx_ws/follow_config.yaml
```

YAML 依靠缩进表达层级，使用空格，不要用 Tab。布尔值写 `true` / `false`。

## 最常修改的项目

| 功能 | 配置位置 | 当前值 |
|---|---|---:|
| 前进速度上限 | `/** → ros__parameters → max_linear` | 1.0 m/s |
| 转向速度上限 | `/** → ros__parameters → max_angular` | 0.5 rad/s |
| 前进加速度 | `follow_velocity_guard → ros__parameters → linear_accel` | 0.5 m/s² |
| 转向角加速度 | `follow_velocity_guard → ros__parameters → angular_accel` | 0.2 rad/s² |
| 保持距离 | `tag_follower → ros__parameters → desired_distance` | 0.5 m |
| 距离死区 | 同上，`distance_deadband` | 0.08 m |
| 速度响应增益 | 同上，`linear_gain` | 0.2 |
| 转向响应增益 | 同上，`angular_gain` | 0.6 |
| 首次确认帧数 | 同上，`acquire_frames` | 1 |
| KF 开关 | 同上，`kf → enabled` | true |
| 近障停车阈值 | `follow_depth_clearance → ros__parameters → stop_distance` | 0.2 m |
| 全图有效率 | 同上，`minimum_valid_fraction` | 0.2，即 20% |
| 分区盲区检查 | 同上，`check_blind_sectors` | false |
| 深度超时检查 | 同上，`check_depth_timeout` | false |

`/**` 是 ROS 2 参数通配匹配。此处只放两个共用限速，让控制器和速度保护同时读取。
**速度上限只改这一处，不要再到两个节点段里重复加 max_linear/max_angular。**
如果添加节点专属的同名参数，它可能覆盖通配参数，造成两处限速不一致。

## 修改示例

例如希望前进上限为 0.3 m/s、加速度为 0.1 m/s²，在原文件对应位置修改：

```yaml
/**:
  ros__parameters:
    max_linear: 0.3
    max_angular: 0.1

follow_velocity_guard:
  ros__parameters:
    linear_accel: 0.1
    # 保留原文件中其他参数
```

此示例只展示相关字段，不要用它替换整个文件。当前实际配置仍是 1.0 m/s 与 0.5 m/s²。
速度上限不等于固定速度；实际输出还受距离增益、偏角、KF、使能、加速度和当前保护结果影响。
`kf.acceleration_std` 是滤波模型的噪声标准差，不是底盘加速度限制。

## 生效步骤

1. 点击控制窗口“停止 / 禁用”，确认车辆停止。
2. 在启动终端按 Ctrl+C，结束旧节点。
3. 保存 `follow_config.yaml`。
4. 重新启动：

```bash
~/agx_ws/scripts/start_all.sh
```

不需要重新编译，运行中的节点也不会自动热更新。
启动后仍默认禁用，要人工点击使能才允许运动。
如果只启动跟随，下面的入口也会读取同一个文件：

```bash
~/agx_ws/scripts/start_tag_follow.sh
```

直接 `ros2 launch bunker_tag_follower bringup.launch.py` 时，包内默认配置也是这份内容在当前 symlink 安装下的引用。
自定义配置可用 `config:=/绝对路径/配置.yaml` 覆盖默认入口。
标记打印尺寸、相机/底盘是否启动、硬件/预览模式仍属于 launch 参数；本文件集中的是跟随、限速、KF 与深度检查参数。
AprilTag 检测 ID/家族的检测器配置仍在单独的检测配置中；改变 tag_id 时仍需同步检测器，不能只改目标选择。

## 检查实际加载值

启动后：

```bash
source ~/agx_ws/setup_humble.bash
ros2 param get /tag_follower max_linear
ros2 param get /follow_velocity_guard max_linear
ros2 param get /follow_velocity_guard linear_accel
```

前两项应该一致。KF 开关可检查：

```bash
ros2 param get /tag_follower kf.enabled
```

## 调参边界

当前近障阈值为 0.2 m，分区和深度超时停车已按现场要求关闭；这些参数不能证明 1 m/s 下有足够停车距离。
相机在车体中间，镜头量到的距离也不是车头净空。修改速度后应重新验证停车距离，保持遥控接管。
参数文件本身不改变使能逻辑，不会因为保存文件自动让车启动。


## 启动前检查参数是否冲突

```bash
~/agx_ws/scripts/check_follow_config.sh
```

检查命令不会启动相机或底盘。总启动和单独跟随启动也会自动执行相同校验。
距离需要满足：

```text
minimum_distance < desired_distance < maximum_distance
desired_distance > minimum_distance + distance_deadband
```

例如 minimum_distance=0.35、distance_deadband=0.08 时，desired_distance 必须大于 0.43。
将保持距离单独改为 0.3 会被拒绝；不要忽略最小距离和死区的约束。
2026-10-21 的启动退出问题由 desired_distance=0.3 与 minimum_distance=0.35 冲突引起，已恢复保持距离 0.5，其余现场参数保留。
